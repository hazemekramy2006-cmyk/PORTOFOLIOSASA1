Benchmarking

Competitive Analysis

Nielsen Norman Heuristic Evaluation of existing productivity applications

Platform Heuristic Rating Observation / Issue Suggestion
Todoist Flexibility and Efficiency ★★★ 3/5 Dense task lists increase cognitive load, making it hard for ADHD users to prioritize and start tasks Simplify task grouping and add step-by-step subtasks
Todoist Recognition rather than Recall ★★★ 3/5 Lack of visual cues forces users to rely on memory Add color coding and priority labels
Forest Aesthetic and Minimalist Design ★★★ 3/5 No task context — only displays "Study" Link timer to tasks for better context
Forest Visibility of System Status ★★★★ 4/5 Progress not very clear Add clearer timer/progress indicator
Microsoft To Do Error Prevention ★★★★ 4/5 Accidental deletion without strong warning Add Undo or Recently Deleted option
Microsoft To Do Flexibility & Efficiency / Match Real World ★★★ 3/5 Static reminders may overwhelm users or be ignored, leading to missed tasks Add micro-steps or automatic task splitting

Key Findings

The benchmarking reveals several common usability issues across all evaluated productivity applications, particularly when used by students with ADHD:

  • Cognitive Overload: Dense interfaces, unstructured task lists, and lack of clear prioritization make it difficult for users with ADHD to process information and focus on tasks.
  • Lack of Flexibility: Rigid reminder systems and fixed task structures don't align with fluctuating attention patterns of ADHD users.
  • Limited Progress Visibility: When users cannot clearly see their progress, it becomes harder to stay engaged and complete tasks.
  • Systemic Mismatch: Existing tools are designed for general users and don't adequately consider ADHD-specific challenges such as attention regulation and executive dysfunction.

Iteration 2 Testing Results

5 Participants (Ages 18-25)

All five participants successfully completed the assigned interactions in the High-Fidelity Interactive Prototype. Key findings:

  • AI Breakdown: Identified as the most impactful feature for reducing task initiation difficulty. All participants confirmed breaking large assignments into smaller subtasks made it significantly easier to begin.
  • Focus Mode: Demonstrated strong usability. Improvements to Pause/Resume controls resulted in smoother interaction. External phone distractions remained a challenge partially addressed by on-screen prompts.
  • Smart Reminders: Consistently described as calm, supportive, and easy to use. Effectively helped users stay aware of deadlines without creating additional stress.
  • Navigation: Generally clear, though three participants experienced brief difficulties locating specific screens (Settings, reminder configuration, Progress Tracking).

All five participants confirmed that Step would be more effective for university students with ADHD than conventional productivity applications.

HCI Principles

Application of HCI Principles

Six core Human-Computer Interaction principles applied in Step

1
Visibility of System Status
The system should always keep users informed about what is going on, through appropriate feedback within reasonable time. Users should be able to see clearly what the current state of the system is and what actions are available to them.

Application in Step

The Home Dashboard displays the user's current academic status at a glance: today's tasks, weekly progress, and focus time statistics are all visible on a single screen without requiring navigation. Progress bars provide immediate visual feedback on task completion. The Focus Mode timer is always prominently displayed so the user always knows how much focus time remains.

2
Consistency and Standards
Users should not have to wonder whether different words, situations, or actions mean the same thing. The interface should follow platform conventions and maintain a uniform visual language — the same colors, icons, typography, and button styles across all screens.

Application in Step

Step uses a consistent blue-and-white color palette across every screen. Buttons, typography, spacing, and card layouts follow the same pattern throughout the app. Action buttons (Add Task, Start Focus, Set Reminder) always appear in the same position and style. This consistency reduces the cognitive effort required to learn the interface — especially critical for users with ADHD who struggle with unpredictable interfaces.

3
Feedback
Every action taken by the user should produce a visible, immediate response from the system. Feedback confirms that the system has received the user's input and communicates the outcome, helping users build a mental model of how the system works and reducing uncertainty.

Application in Step

Step provides multiple layers of feedback: (1) A success popup — "Task added successfully!" — appears immediately after the user adds a task. (2) Progress bars update in real time as tasks are completed, giving visual confirmation of progress. (3) The Focus Mode timer counts down live, providing continuous temporal feedback. (4) Smart Reminders send timestamped notifications to confirm upcoming task awareness.

4
Error Prevention
Good design prevents problems from occurring in the first place. Rather than simply providing good error messages, the system should be carefully designed to prevent users from making mistakes — particularly irreversible ones — through confirmation dialogs, constraints, and clear affordances.

Application in Step

Step prevents errors through a structured Add Task form that guides users step by step. Each field is clearly labeled — Task Title, Notes, Due Date, Priority Level, and Reminder — reducing the chance of missing or incorrect input. The Priority selector (Low / Med / High) prevents ambiguity in task organization by making options explicit and visible. Delete confirmation dialogs prevent accidental deletion.

5
User Control and Freedom
Users often choose system functions by mistake and will need a clearly marked "emergency exit" to leave the unwanted state. The system should support undo and redo and give users the feeling that they are in control of the interface — not the other way around.

Application in Step

Step gives users explicit control throughout the application. In Focus Mode, users can pause, resume, or cancel a focus session at any time without penalty. The Smart Reminder system includes a Snooze option — users can delay a reminder without dismissing it — respecting the user's current cognitive state while keeping the task active. Priority levels (Low / Medium / High) give users control over how their tasks are organized and presented.

6
Recognition Rather Than Recall
The system should minimize the user's memory load by making objects, actions, and options visible. Users should not have to remember information from one part of the interface to another. Instructions for use of the system should be visible or easily retrievable whenever appropriate.

Application in Step

Step is designed so users never have to memorize how to use it. Every screen uses familiar icons paired with text labels so users recognize functions without having to recall them. The AI Breakdown feature offers ready-made prompt suggestions ("Break down my study task", "Create a focus plan") so users do not need to remember or formulate what to ask. Task priority levels are labeled in text (Low / Medium / High) rather than requiring users to remember color codes alone.

Typography System

Primary Typeface

SF Pro Display / Roboto — System default sans-serif optimized for mobile retina displays. Anti-aliased rendering for crisp text.

Language Support: Latin (English) — primary display language in prototype

Type Scale

Carefully designed hierarchy from 24pt Display titles to 10pt Caption labels. Bold (700) for headings, Regular (400) for body text.

WCAG AA: Minimum 4.5:1 contrast ratio for body text; 3:1 for large text

Spacing & Grid System

4pt Base Unit

All padding, margin, and gap values are multiples of 4pt for harmonious layout rhythm. Standard screen margins: 16pt (space-4).

4-Column Grid

Mobile-first design with 375pt base width. 4 columns with 16pt gutters and margins. Content width: 343pt. Row grid: 8pt increments.

Responsive Breakpoints

Small Phone (320pt), Standard Phone (375pt), Large Phone (414pt), Tablet (768pt+). Layout adapts with font scaling and column adjustments.

Ethics & Accessibility

Inclusivity & Ethics

Building an accessible, ethical, and inclusive application

Accessibility Compliance

Color Contrast

Carefully selected color palette with sufficient contrast between text and background elements. Ensures readability for users with visual impairments or color vision deficiencies.

Font Size & Typography

Clear and readable font sizes across different screen sizes. Avoided overly small text with proper spacing between lines and elements. Improves readability for users with low vision.

Navigation & Usability

Simple and consistent navigation structure. Clearly labeled menus and buttons allow users to move between screens easily without confusion. Supports users with cognitive disabilities.

Screen Reader Support

Interface designed to be compatible with screen readers. Clear labels for buttons, icons, and input fields allow visually impaired users to understand and interact effectively.

Alternative Text

All important images and icons include alternative descriptions (alt text). Ensures users who rely on screen readers can understand the purpose of visual elements.

WCAG Compliance

Follows basic WCAG principles ensuring the interface is perceivable, operable, understandable, and robust. Makes the application more inclusive and user-friendly for all users.

Ethics & Privacy

Privacy and Data Protection

Follows data minimization principles by limiting information requests to what is necessary for task management and productivity support.

Informed Consent

During usability testing, participants were informed about the purpose of the study and voluntarily agreed to participate before completing the testing sessions.

Avoiding Dark Patterns

The application was designed to support users without manipulating their decisions. Users maintain full control over their tasks, reminders, notifications, and focus sessions.

Transparency

The system provides clear feedback through progress indicators, task statuses, reminders, and focus timers. Users always understand the results of their actions and the current system status.

Persuasive Design Techniques

Reminders

Smart reminders help users remember important tasks and deadlines. Reduces forgetfulness and encourages timely completion.

Goal Setting

Users create tasks, assign priorities, and set due dates. Helps define clear objectives and stay organized.

Progress Tracking

Visual progress indicators, weekly charts, and focus progress motivate users by showing achievements and encouraging continuous improvement.

Task Breakdown

AI-powered task decomposition divides large tasks into smaller steps. Reduces cognitive overload and helps users start tasks more easily.

Focus Mode

Dedicated timer and distraction-free environment with motivational messages. Encourages users to stay engaged and improve productivity.
